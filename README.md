# SmartFran × Javier Mammana · Propuesta de Community Manager

Proyecto de presentación web estática listo para publicar en GitHub Pages.

## Archivos principales
- `index.html`: presentación completa con campañas, video, plan de contenido, organización editorial y perfil profesional.
- `styles.css`: diseño responsive para desktop, tablet y móvil.
- `script.js`: interacciones de carruseles, selección de ejes, fases de planificación y calendario semanal.
- `assets/`: seis piezas de feed 1080 × 1350, fotos editoriales originales, video vertical MP4 de 12 segundos.

## Publicar en GitHub Pages
1. Descargá y descomprimí el ZIP.
2. Subí todos los archivos y carpetas a la raíz de un repositorio de GitHub.
3. Abrí **Settings → Pages**.
4. En **Build and deployment**, elegí **Deploy from a branch**, rama `main` y carpeta `/ (root)`.
5. Guardá y esperá a que GitHub informe la URL publicada.

## Interacciones incluidas
- Carruseles de SmartPedidos y SmartFran Cloud con botones, miniaturas y descarga de placa.
- Tres pestañas para explorar los ejes de contenido: educación, autoridad y conversión.
- Fases seleccionables de trabajo: planificación (mes -2), producción y aprobación (mes -1), publicación y optimización (mes activo).
- Vista semanal interactiva de una posible agenda editorial.

## Nota para una presentación profesional
Las imágenes son recursos conceptuales creados para esta propuesta, no fotografías oficiales de clientes SmartFran. Las funcionalidades y los ejemplos se plantean a partir de la información pública disponible en smartfran.com. Antes de publicar las piezas como comunicación oficial, validar nomenclatura, integraciones de pago, funcionalidades de Cloud, cifras, testimonios y permisos con el equipo SmartFran. Casos y resultados deberán ser reales y aprobados.
